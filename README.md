# Sales-Performance-Customer-Insights
Developed a Sales Performance &amp; Customer Insights Dashboard using Excel, Python, Pandas, and SQL. Cleaned and analyzed 1,000+ sales records, created KPIs and interactive dashboards, identified sales trends, top products, customers and regions, and generated actionable business insights through data visualization.

Sales Performance & Customer Insights Dashboard

Project Overview

The Sales Performance & Customer Insights Dashboard is a beginner-friendly Data Analytics project designed to analyze sales data and generate meaningful business insights.

The project uses Excel, Python, Pandas, Matplotlib, and MySQL to clean, analyze, visualize, and understand sales performance across products, customers, regions, payment methods, and sales channels.

Business Problem

The company wants to understand its sales performance and customer behavior. The analysis helps identify top-performing products, high-revenue regions, customer trends, monthly sales patterns, and the most effective sales channels.

Objectives

• Clean and prepare sales data for analysis
• Calculate important business KPIs
• Analyze monthly sales trends
• Identify top-performing products and customers
• Compare sales across states and product categories
• Analyze payment methods and sales channels
• Create an interactive Excel dashboard
• Generate actionable business insights

Dataset

The dataset contains 1,000+ realistic sales records covering January 2025 to December 2025.

Main columns include:

• Order_ID
• Order_Date
• Customer_ID
• Customer_Name
• Gender
• Age
• City
• State
• Product_Category
• Product
• Quantity
• Unit_Price
• Discount
• Sales
• Payment_Mode
• Sales_Channel

Sales is calculated using:

Sales = Quantity × Unit_Price × (1 - Discount)

How to Run

Step 1: Download or clone the project from GitHub.

Step 2: Install the required Python libraries:

pip install -r requirements.txt

Step 3: Open the Excel dashboard:

excel/Sales_Performance_Dashboard.xlsx

Step 4: Run the Python analysis:

python python/sales_analysis.py

Step 5: Open MySQL and execute:

sql/sales_analysis.sql

Step 6: Review the generated charts and business insights.
